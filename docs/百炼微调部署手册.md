# LexiConstrain 阿里云百炼微调部署手册

> 目标：把 LexiConstrain（Qwen2.5-7B-Instruct + SFT + DPO）托管到阿里云百炼专属服务，
> 替代自建 GPU 服务器，获得稳定的 OpenAI 兼容 API。
> 生成日期：2026-09-07 · 配套数据已导出至 `data/bailian/`

---

## 〇、你要准备的东西

- 阿里云账号（实名认证）+ 开通百炼（Model Studio）服务：https://bailian.console.aliyun.com
- 训练数据（已生成好，直接用）：
  - `data/bailian/bailian_sft_train.jsonl` — SFT 数据 **2040 条**（ChatML 格式）
  - `data/bailian/bailian_dpo_train.jsonl` — DPO 偏好对 **2040 条**（百炼偏好训练格式）
  - 如需重新生成/扩量：`python model_training/07_export_bailian.py`（确定性合成，可复现）

## 一、上传数据集（约 5 分钟）

1. 百炼控制台左侧 → **模型调优 → 数据集管理**
2. **导入数据集** → 选择「文件上传」→ 上传 `bailian_sft_train.jsonl`，类型选**模型微调/对话**
3. 同样方式上传 `bailian_dpo_train.jsonl`（类型按平台提示选偏好训练对应类型）
4. 上传后平台会做格式校验，校验通过即可用

## 二、SFT 微调任务（平台排队+训练约 0.5~2 小时）

1. **模型调优 → 训练新模型**
2. 调优方式：**SFT（模型微调）**
3. 基础模型：**qwen2.5-7b-instruct**
4. 训练集：选刚上传的 SFT 数据集
5. 超参建议（平台默认值基本可用，重点看这几项）：
   - 训练算法：**LoRA**（性价比高；追求极致可选全参，更贵更慢）
   - Epoch：**2~3**（数据 2040 条规模建议 3）
   - 学习率：默认（LoRA 通常 1e-4 量级）
   - 高级选项里若有「混合通用数据集」建议**开启**（防止过拟合导致通用能力退化）
6. 提交任务，等待训练完成（按量计费，这个数据量费用很低）

## 三、DPO 偏好对齐（在 SFT 产出之上）

1. 在 SFT 产出的模型上 → **继续调优 / 训练新模型**
2. 调优方式：**DPO（偏好训练）**
3. 训练集：`bailian_dpo_train.jsonl` 对应数据集
4. β (beta) 建议 0.1，学习率默认（DPO 学习率要小，5e-6 量级）
5. 完成后得到最终模型「LexiConstrain」

## 四、部署为专属服务

1. 模型调优页面 → 选中最终模型 → **部署**
2. 选择按量计费（比赛期间随开随停，不演示时停掉省钱）
3. 部署完成后获得**专属模型标识（endpoint）**，记录下来

## 五、接入 wordlink-main（改两行配置）

部署完成后，`.env` 修改：

```bash
# 原来指向 SiliconFlow：
# LLM_BASE_URL=https://api.siliconflow.cn/v1
# LLM_MODEL=deepseek-ai/DeepSeek-V3

# 改为百炼专属服务（OpenAI 兼容模式）：
LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
LLM_MODEL=<你的专属模型标识/endpoint 名>
# SILICONFLOW_APIKEY 换成百炼的 API-KEY（控制台右上角获取）
```

代码无需改动——`src/lib/ai/gateway.ts` 走的就是 OpenAI 兼容协议。

## 六、成本与风险提示

| 项目 | 预估 |
|---|---|
| SFT 训练（LoRA, 2040 条） | 低（按量计费，通常几元~几十元） |
| DPO 训练 | 与 SFT 同量级 |
| 专属服务部署 | **大头在这里**：按实例时长计费。比赛演示期间开启，平时停掉 |
| API 调用 | 按 token 计费，量小可忽略 |

风险与备选：
- 若百炼个别版本不开放 7B 微调（以控制台可选模型列表为准），退路是 **PAI Model Gallery**
  （同样支持 Qwen2.5-7B 的 SFT+DPO+部署，流程稍重），或回到 GPU 服务器方案
  （`python model_training/run_pipeline.py --full_train`，手册见 MODEL_TRAINING_PIPELINE.md）。
- 答辩口径：「LexiConstrain 训练于确定性合成语料（2040 条，CEFR 硬约束过滤），微调与部署托管于阿里云百炼」。

## 七、与本地管线的关系（答辩讲法）

- 本地 `model_training/01~07` 脚本 = **数据工程 + 可复现训练管线 + 真实评测**（Edge 侧在本机完成全流程）
- 云端百炼 = **LexiConstrain 7B 的算力与托管**（不必自购 GPU）
- 两侧共用同一套数据与评测协议，指标可比。
