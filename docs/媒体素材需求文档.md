## M1 — Hero 全屏背景视频

- **用途**:首屏全屏背景。中央为衬线大标题「一词,连成星图」、邮箱订阅胶囊、产品理念按钮。
- **规格**:16:9,≥ 1920×1080,8–20 秒,**可无缝循环**。
- **播放行为**:静音、自动播放、`object-cover object-bottom`;代码已实现淡入淡出循环(临近结尾 0.55s 淡出至黑场 → 重置 → 淡入),素材**不需要**自带交叉溶解。
- **画面要求**:
  - 暗色调为主(页面底色纯黑),低亮度、高质感;
  - 主题建议:星空 / 星座连线 / 深海光点等「联结成网」意象,呼应认知星图概念;
  - **画面内不得包含文字、Logo、水印**;
  - 中央区域会被标题遮挡,关键视觉放画面上半部或四周。

## M2 — 核心演示视频(Featured)

- **用途**:圆角 24px 大幅展示窗,左下叠加「我们的方法」玻璃卡片与「了解更多」按钮。
- **规格**:16:9,≥ 1600×900,10–30 秒,静音自动循环。
- **画面要求**:
  - 首选:**产品真实录屏**——查词 → 星图连线 → 多模块展示 → 测验的完整闭环演示(可加速剪辑);
  - 备选:抽象数据联结动画;
  - 左下约 25% 区域有渐变遮罩和文字卡片,**左下角避免关键内容**。

## M3 — 学习闭环演示(Philosophy)

- **用途**:左侧 4:3 圆角媒体位,右侧为「查词入图 / 抗遗忘巩固」文案。
- **规格**:4:3,≥ 1200×900;视频(静音循环)或静态图均可,图片请提供 WebP + JPG 两版。
- **画面要求**:展示星图生长过程或词根积木拆解动画;中低亮度,无文字水印。

## M4 — 服务卡片视频 ×2

- **用途**:两张 liquid-glass 卡片顶部 16:9 媒体区(hover 缓慢放大 105%)。
- **规格**:16:9,≥ 1280×720,6–15 秒短循环,两支风格统一。
- **主题建议**:
  - 卡片一(七大学习模块):词卡翻动、例句滚动、视频切片网格等「多维输入」蒙太奇;
  - 卡片二(三种测验模式):答题交互、正确率反馈、遗忘曲线绘制的抽象动效。

## 通用技术要求

1. **格式**:MP4(H.264),建议附 WebM(VP9);单文件 ≤ 8MB,码率 4–6 Mbps。
2. **帧率**:30fps;循环素材首尾帧必须连续。
3. **色彩**:以黑 (#000) 为底的暗色系;白色文字直接叠加在画面上,素材不得干扰阅读。
4. **交付方式**:上传 CDN 后把 URL 填入 `src/lib/welcome-media.ts`,或放入 `public/media/` 填相对路径(如 `/media/hero-bg.mp4`)。
5. **验收前必测**:M1 的淡入淡出循环逻辑需在 Chrome / Safari / Edge 实测,循环处无明显跳变;各素材在 375px 移动端裁切后主体完整;无画面内文字 / 水印。
