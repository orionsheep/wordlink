一、 EchoStream 阅读引擎 4 大核心资产剖析

Source Architecture

经过对仓库源码的深入挖掘，这个阅读系统的本质不是页面，而是以下 4 个高内聚、高复用度的纯逻辑引擎：

Module 01 · 纯算法引擎
句子对齐与缩写保护 (sentences.ts)
• 40+ 英文缩写保护（防止 Mr.、Dr.、i.e.、U.S. 因句点被错误截断）；
• 字符长度权重对齐算法：当英文 $M$ 句与中文 $N$ 句数量不等时，按字符比例精准映射为 { en, zh } 对。
Module 02 · 音频调度引擎
双模音频时间轴调度 (audio-driver)
• 句级预生成音频流 (IndexTTS)：维护 audio_sentences 播放队列，监听 onEnded 平滑换句；
• 字级时间戳字幕流 (Whisper)：基于 currentTime rAF 追踪，计算当前活跃句与活跃词。
Module 03 · 词级交互引擎
分词与词形还原 (tokenizer & lemmatizer)
• 分词解析器：将文本拆分为带 data-word 属性的交互式 Token；
• 词形还原：自动将时态/复数还原为词典原形（luminousness → luminous）；
• 坐标定位气泡：计算屏幕 (x, y) 呼出操作菜单。
Module 04 · 知识多级解析
多维语法文化讲解 (explanations)
• 三档语法切片（low / mid / high 适合初级到考研）；
• DeepSeek 实时段落语境答疑（AIChatPanel 流式对话）。

二、 WordLink 代码级移植路径 (File-Level Implementation)

在 WordLink 内部建立独立的纯函数引擎目录 src/lib/reader-engine/，完全解耦：

Step 1 · 移植分词与对齐算法
src/lib/reader-engine/sentences.ts
直接复制 EchoStream 的分句与中英对齐算法，零额外依赖。提供 splitEnglishSentences() 与 alignSentences()。
Step 2 · 移植词级 Tokenizer
src/lib/reader-engine/tokenizer.ts
将一段英文句子快速切分为带可点选标记的 Token 数组，为后续呼出 WordLink 星图气泡做准备：
export interface WordToken {
    text: string;      // 原始文本 (如 "luminous,")
    cleanWord: string; // 纯单词 (如 "luminous")
    isWord: boolean;   // 是否为可查词汇 (排除空格与标点)
}

export function tokenizeSentence(sentence: string): WordToken[] {
    return sentence.split(/(\s+|[.,!?;:"()]+)/).filter(Boolean).map(token => ({
        text: token,
        cleanWord: token.toLowerCase().replace(/[^a-z-]/g, ''),
        isWord: /^[a-zA-Z-]+$/.test(token)
    }));
}
Step 3 · 双模音频调度器 (支持 IndexTTS + Web Speech 降级)
src/lib/reader-engine/audio-timeline.ts
统一管理句子音频队列：优先播放 EchoStream 生成的句级音频（高音质），无音频时平滑回退至浏览器 Web Speech API：
export class AudioTimelineEngine {
    playSentence(sentence: { audioUrl?: string; text_en: string }, onEnded: () => void) {
        if (sentence.audioUrl) {
            // 优先使用预生成句级音频
            const audio = new Audio(sentence.audioUrl);
            audio.onended = onEnded;
            audio.play();
        } else {
            // 自动回退至浏览器 TTS 朗读
            voiceEngine.speak(sentence.text_en, 0.88, onEnded);
        }
    }
}

三、 双宿主场景融合 (How WordLink Hosts the Engine)

这个阅读引擎在 WordLink 中不是单一孤立页面，而是**被两个不同维度的场景完整承载**：

宿主 A · 屏保沉浸空间 /ambient (Reading Mode)
车窗逐句听读与环境声景
• 定位：零操作、环境陪伴、被动语言习得；
• 运作机制：sentences.ts 对齐句子流 → SentenceCard 在四季车窗上大字逐词点亮 → Web Audio 声景自动避让压低至 35%；
• 自愈闭环：DeepSeek 提取用户近期学过的生词现场生成故事。
宿主 B · 长文精读工作台 /read/[id] (Study Hub)
双语长文研读与星图裂变
• 定位：深度交互、词汇扩充、主动精读；
• 关键质变（最核心）：用户在长文中点击任意生词，不再是简单复制，而是直接唤出 WordLink 的 Cyber-Crystal 裂变星图气泡；
• 数据入库：点击「收藏」直达 UserLibraryWord，进入听写强化池。
💡 核心质变：点词从「复制」升级为「裂变认知星图」

在 EchoStream 原始代码中，选中单词仅弹出复制菜单；融合后，点击单词直接触发 WordLink 本地服务：
onWordClick(word) ──► getFissionData(word) ──► 弹出 2D 裂变晶体 (PanelFissionGraph) ──► 写入 UserLibrary
