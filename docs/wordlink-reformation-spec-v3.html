一、 痛点深度剖析与重构使命 (Why We Must Reform)

市面上的英语单词与阅读软件有千万个，但都陷在以下三大死穴中：

PAIN POINT 01
孤立闪卡与语境断层
刷了几千张单词卡，在真实文章中依然读不懂、用不出。单词脱离了生动的上下文，成了死记硬背的负担。
PAIN POINT 02
读与背割裂为两件事
用户在阅读器里读文章，还得退出打开另一个背单词软件去完成打卡任务，切换摩擦极大，极易放弃。
PAIN POINT 03
算法为流量而非学习服务
现有信息流推荐只根据用户偏好推荐内容，根本不知道用户哪些词正在遗忘、哪篇文章正好能起到复习作用。
“下一篇文章，就是你的单词复习。”
用户不需要离开阅读场景专门打卡——系统推荐或现场生成的每一篇短文，都精准包含用户当天艾宾浩斯曲线上即将遗忘的生词。

二、 终极数据流转与闭环飞轮 (The Cognitive Flywheel)

Step 01 · 真实长文语境输入
EchoStream 长文精读与原声对齐 (/read)
精读双语外刊长文与视频原声，遇到生词点击触发「全息词汇捕获」协议，瞬间落库至用户专属生词库。
Step 02 · 认知星图裂变拓展
WordLink Cyber-Crystal 图谱重构 (/study)
单个生词就地展开为 2D/3D 词根前缀后缀辐射网络，打通 8 大子模块（原声切片、意象图解、词态积木）。
Step 03 · 听写输出与自愈强化
AI 听写智能体与 SM-2 调度 (/quiz/dictation)
FSRS-6 算法调度遗忘临界词，进行麦克风语音转写、声波打分与字符级 Diff 拼写自愈，形成双轨输出能力。
Step 04 · 下一篇专属短文自愈
Ambient DeepSeek 微语境重逢 (/ambient)
DeepSeek 将当前到期词即时编织进一篇 100 词诗意短文，在四季车窗实景中逐句慢读，把被动时间转化为长时记忆。

三、 四大维度深度重构技术规范 (Four Reformation Dimensions)

1. 记忆模型重构：SM-2 → FSRS-6 动态保持率实时投影

在浏览器端和后端实时计算每个单词的瞬时记忆保持率 R(t) = (1 + factor · t/S)^(-w)。

• 有效曝光 (Exposure)：段落停留超 2.5 秒，自动提取 Lemma 作为正向识别证据；
• 查词犹豫 (Hesitation/Click)：点击单词查星图，判定为「需要帮助」，立即降低稳定性 S 并排入到期复习；
• 听写结果 (Production)：听写拼写差异（Levenshtein 距离）直接作为 FSRS Grade (1~4)。

2. 推荐引擎重构：RME-V5 多目标纯函数打分器 + DeepSeek 兜底生成 

// RME-V5 6 维归一化评分公式 (Pure Function Scorer)
FinalScore = 100 * (
    0.28 * OpportunityScore   // 命中到期词数量权重 (核心)
  + 0.24 * InterestScore      // 主题兴趣匹配度
  + 0.15 * DifficultyScore    // |用户 CEFR - 文章 CEFR| 等级匹配
  + 0.18 * GoalScore          // 考试目标加权 (CET4 / 考研 / 托福)
  + 0.08 * NoveltyScore       // 主题新鲜度与防疲劳
  + 0.07 * LengthScore        // 篇幅阅读时长匹配
)

超越 ReadAge 的杀手锏：当静态文库没有命中到期词时，自动触发 POST /api/ambient/articles/generate，DeepSeek 现场 2 秒生成包含这些生词的专属故事，实现无限个性化语境供给！

3. 阅读引擎重构：点词呼出星图裂变工作台

在长文精读页 /read/[id] 中，点击任意单词不再是简单复制，而是直接呼出 Cognitive Studio 抽屉： 展示音标、中文释义、词根词缀积木，并支持一键收藏入库实时进入当晚听写池。

4. 沉浸屏保空间重构：纯净车窗实景 + 1200ms 电影级溶接 + 首尾闭环

完全移除黑屏遮罩，开局即满画质春季雪山；移除人造花瓣干扰，回归纯净实景车窗；双模控制条自适应展示；冬夜雪景平滑溶接回初春雪山，达成 100% 完美的循环相接。
