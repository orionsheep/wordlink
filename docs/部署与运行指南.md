# WordLink 英语词汇裂变 — 环境依赖说明 / 部署步骤 / 运行指南

本文档面向评审与复现人员，覆盖从零开始在本机或服务器上部署、运行、验证 WordLink 全部功能所需的所有步骤。

---

## 1. 项目简介

WordLink（LPT 英语俱乐部-单词系统）是一个基于 **Next.js 16 (App Router) + React 19 + TypeScript** 的英语词汇学习平台，核心能力包括：

- **词汇裂变图谱**：基于 `react-force-graph-2d` / `d3-force` 的力导向图，围绕目标词展示同义词与二级关联词；
- **单词详情**：英文释义、中文释义、音标、词形变换、例句、易混词对比、AI 讲解；
- **词库学习**：内置考试词库（四六级/考研/托福等）+ 用户自定义词库（创建/导入/分组学习）；
- **测验练习**：选择、拼写、回忆等多种题型，结合 `UserWordState` 记忆强度模型安排复习；
- **学习记录**：访问历史、测验成绩、打卡（CheckinLog）、学习进度仪表盘；
- **AI 智能体矩阵**：单词讲解（Tutor）、学习导航（Navigator）、单词护照（Passport）等，经统一 AI 网关（`src/lib/ai/gateway.ts`）调用 DeepSeek / SiliconFlow，提示词模板集中于 `data/ai_prompts/`，生成结果落盘缓存于 `data/generated/`，保证演示不依赖实时 API；
- **沉浸式阅读**：Ambient 文章库（`AmbientArticle`）+ 阅读引擎（`src/lib/reader-engine`），点击查词、生词本联动；
- **中英双语界面**：`next-intl`（文案位于 `messages/zh.json`、`messages/en.json`）。

## 2. 环境依赖

| 依赖 | 版本要求 | 说明 |
| --- | --- | --- |
| Node.js | ≥ 20.x（推荐 20 LTS / 22 LTS） | Next.js 16 与 Prisma 5 的运行要求 |

| Prisma CLI | 5.22.x（项目内 devDependency） | 通过 `npx prisma` 调用，无需全局安装 |

核心依赖（完整清单见 `package.json` / `package-lock.json`）：

- `next@16.0.5`、`react@19.2.0`、`typescript@5`
- `@prisma/client@5.22`（ORM，数据库 schema 见 `prisma/schema.prisma`，schema 名 `LPT_english`）
- `@supabase/ssr`、`@supabase/supabase-js`（登录认证会话）
- `react-force-graph-2d`、`d3-force`（词汇图谱可视化）
- `next-intl`（国际化）、`tailwindcss@4`（样式）
- `papaparse`（词库 CSV 解析）、`lru-cache`（进程内缓存）、`@tanstack/react-virtual`（长列表虚拟滚动）

## 3. 环境变量

在项目根目录创建 `.env` 文件（可参考下表逐项填写）：

| 变量名 | 必填 | 示例 / 说明 |
| --- | --- | --- |
| `DATABASE_URL` | ✅ | `postgresql://postgres:postgres@localhost:5432/english_word_fission_dev?schema=LPT_english` |
| `NEXT_PUBLIC_SUPABASE_URL` | 登录功能需要 | Supabase 项目地址；**不配置时应用进入免登体验模式**（首页/图谱/学习/测验/阅读等公开页面可完整浏览，数据写操作不可用） |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | 登录功能需要 | Supabase 匿名 key |
| `SUPABASE_SERVICE_ROLE_KEY` | 服务端管理操作需要 | Supabase service role key |
| `LLM_BASE_URL` | AI 功能需要 | 默认 `https://api.siliconflow.cn/v1`（OpenAI 兼容协议） |
| `LLM_MODEL` | AI 功能需要 | 默认 `deepseek-ai/DeepSeek-V3.2` |
| `SILICONFLOW_APIKEY` 或 `DEEPSEEK_APIKEY` | AI 功能需要 | 大模型服务密钥；缺失时 AI 讲解/导航等功能自动降级（不影响其余功能） |
| `AUTH_API_BASE` | 可选 | 外部认证服务地址（生产环境使用） |
| `DEMO_MODE` | 可选 | 设为 `true` 启用**离线演示模式**：使用内置演示账号（demo@wordlink.test）免 Supabase 登录体验全部功能，配合 `npx tsx scripts/inject-demo-data.ts` 注入 6 个月拟真学习数据（展会演示/评审/离线复现场景） |

> 复现提示：评审只需验证"图谱/词库/测验/阅读"等核心功能时，**仅配置 `DATABASE_URL` 即可启动**，无需任何外部服务密钥。

## 4. 本地部署步骤（从零到运行）

```bash
# ① 安装依赖
npm install

# ② 启动 PostgreSQL（推荐，需本机已装 Docker）
docker compose up -d
#   容器名 english-word-postgres，账号密码 postgres/postgres，
#   数据库 english_word_fission_dev，端口 5432
# 若使用自备 PostgreSQL，请跳过并相应修改 .env 的 DATABASE_URL。

# ③ 创建 .env 文件（至少包含 DATABASE_URL，见第 3 节）
cat > .env <<'EOF'
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/english_word_fission_dev?schema=LPT_english"
EOF

# ④ 应用数据库迁移（创建 LPT_english schema 与全部数据表）
npx prisma migrate deploy

# ⑤ 生成 Prisma Client
npx prisma generate

# ⑥ 导入词库数据（约 1 万+ 词条的四类语料，见第 5 节）
npm run migrate          # 即 tsx scripts/migrate-to-database.ts
npm run verify           # 校验导入结果（可选）

# ⑦ 启动开发服务器
npm run dev              # http://localhost:3000
```

### （可选）注入演示学习数据

```bash
npx tsx scripts/inject-demo-data.ts
```

该脚本会为演示账号写入约 6 个月的拟真学习数据（访问记录、测验成绩、打卡、笔记等），用于展示仪表盘与学习统计效果。

## 5. 词库数据说明

`data/` 目录包含四类语料，由 `scripts/migrate-to-database.ts` 统一导入：

| 目录/文件 | 内容 | 入库表 |
| --- | --- | --- |
| `word_text_database/word_database/*.md` | 单词深度解析（词源、辨析、例句） | `word_markdown` |
| `word_chinese/*.json` | 中文释义、音标、词形、易混词对比 | `word_chinese` |
| `ecdict_extracted.csv` | ECDICT 词典（音标/中文释义/柯林斯星级/词形变换） | `word_ecdict` |
| `word_fission_data.csv` | 词义裂变关系（词性、释义、同义词） | `word_fission` |
| `ai_prompts/*.txt` | AI 智能体提示词模板 | （文件系统读取） |

导入完成后 `words` 主表与四张子表以 `wordId` 关联，API 按需联查。

## 6. 生产部署

### 6.1 构建与启动

```bash
npm install              # 安装依赖（服务器上可加 --production=false 以包含 dev 依赖用于构建）
npm run build            # 产物在 .next/
npm start                # 默认监听 3011 端口（见 package.json）
```

### 6.2 PM2 守护进程（推荐）

仓库已提供 `ecosystem.config.js`：

```bash
npm i -g pm2
pm2 start ecosystem.config.js   # 应用名 english-word-fission，端口 3011
pm2 save && pm2 startup
```

### 6.3 Docker / 云服务器

- 数据库：直接复用 `docker-compose.yml`（生产环境建议使用云数据库 RDS for PostgreSQL，华为云部署时可搭配 ELB 与安全组放通 80/443）；
- Node 进程建议置于 Nginx 反向代理之后（`proxy_pass http://127.0.0.1:3011;`），并开启 gzip/brotli 与静态资源缓存；
- `.env` 属敏感配置，切勿提交仓库或打包进公开产物。

## 9. 常见问题（FAQ）

1. **`prisma.wordFission is not a function / undefined`**：Prisma Client 与 schema 不同步，执行 `npx prisma generate` 后重启 dev server（详见 `docs/TURBOPACK_PRISMA_ISSUE.md`）。
2. **dev server 启动报 Prisma 初始化错误（Turbopack）**：本项目 `npm run dev` 使用 webpack 模式；若自定义开启 Turbopack，需在 Prisma 配置中显式指定 client 输出路径。
3. **端口冲突**：dev 默认 3000、生产 start 默认 3011，可在命令行用 `-p` 或 `PORT` 环境变量覆盖。
4. **导入脚本中途失败**：脚本可重复执行（幂等 upsert），修正问题后直接重跑 `npm run migrate`。
5. **AI 功能无响应**：检查 `.env` 中 `SILICONFLOW_APIKEY`/`DEEPSEEK_APIKEY` 与 `LLM_BASE_URL`；演示模式下 `data/generated/` 已有缓存结果时不受影响。
