一、 核心商业闭环与教育飞轮 (The 4-Step Learning Flywheel)

闭环验证通过 ✅

打破传统单点工具“背了就忘、读不懂、无法输出”的断层，建立 **输入 → 裂变 → 强化 → 自愈** 的全自动学情自驱飞轮：

Step 01 · Authentic Input
1. 真实语境输入 (EchoStream)
基于母语者原声长文、视频与双语对齐字幕精读；阅读过程中点击任意生词，触发「全息词汇捕获」协议，瞬间落库至用户专属生词库。
Step 02 · Cognitive Fission
2. 认知裂变与星图重构 (WordLink)
Cyber-Crystal 辐射晶体拓扑引擎将单个生词裂变为一整张词根词缀衍生网，挂载 8 大中栏子模块（原声切片、意象图解、词态积木）。
Step 03 · Ebbinghaus Retention
3. 抗遗忘强化与自愈闭环 (Dictation)
SM-2 艾宾浩斯抗遗忘算法实时计算记忆衰减指数，AI 听写智能体调度临界词与错词进行语音转写、声波打分与字符级 Diff 拼写自愈。
Step 04 · Ambient Micro-Story
4. 屏保级沉浸自愈 (Ambient DeepSeek)
DeepSeek 将用户刚学完的生词编织成 $0 边际成本的专属微故事，在四季声景车窗中逐句慢读，把零碎碎片时间转化为无意识语言习得。
“You learn the words. The words become your story. The story feeds your memory.”
—— 答辩核心价值主张（The SDG 4 Personal Learning Flywheel）

三、 四大 AI 智能体协同矩阵 (Four AI Agent Matrix)

系统不依赖单一单薄的通用聊天框，而是部署了四个各司其职的专业 Agent：

智能体名称 底层模型 / 算法 触发场景 输出产物与教育价值
🤖 1. 词语裂变智能体 (Fission Agent) DeepSeek-V3.2 + 本地词根库 三栏工作台浏览词汇 2D/3D 裂变拓扑网络，拆解词根前缀后缀积木
🎙️ 2. 听写自愈智能体 (Dictation Agent) Web Speech API + SM-2 + Diff 听写测验 / 复习轮次 实时声波打分、字符级差异诊断提示、错词闭环重测池
📜 3. 微语境生成智能体 (Story Weaver) DeepSeek-V4-Flash (SiliconFlow) Ambient 屏保阅读 / 错词自愈 将用户近期 5~10 个生词织入 100 词诗意短文，提供中英双语对照
🎧 4. 原声语境切片智能体 (Context Agent) Whisper ASR + YouGlish 引擎 单词多维解释工作台 母语者真实世界视频片段精准时间戳切片与口型示范

四、 四季沉浸声景与声学避让规范 (Soundscape & Audio Ducking)

采用纯原生 Web Audio API 实时振荡器与噪声滤波合成，零外部音频依赖，秒开且省流量：

🌸 春 · 细雨鸟鸣
白噪声低通滤波 (1400Hz) 模拟细雨 + 随机正弦双音节 (2300~3300Hz) 模拟林鸟清啼
✨ 夏 · 夜风蝉鸣
粉噪声 (420Hz) 模拟夜风 + 4200Hz 窄带调幅方波阵发模拟夏夜远蝉
🍁 秋 · 林叶落霞
棕噪声 (320Hz) 正弦缓慢起伏模拟阵风 + 带通白噪脉冲 (1500Hz) 模拟林叶沙沙
❄️ 冬 · 篝火飞雪
超低频棕噪 (140Hz) 模拟暖炉 + 三角波随机微爆点模拟柴火噼啪 + 8000Hz 微白噪
智能音频避让 (Side-Chain Ducking)：当 TTS 发音或文章句子开始朗读时，声景与背景音乐以 0.12s 渐变衰减至 35%；朗读结束后 0.4s 平滑恢复，保持听力清晰。
